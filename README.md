# Project_WF_nhom1_PM_QLSV

## Giới thiệu

**Project_WF_nhom1_PM_QLSV** là phần mềm quản lý sinh viên được xây dựng bằng **C# WinForms**.  
Phần mềm giúp nhà trường và giảng viên quản lý thông tin sinh viên một cách dễ dàng, nhanh chóng và hiệu quả.

## Công nghệ sử dụng

- C#
- Windows Forms
- SQL Server
- Visual Studio

## Chức năng chính

- Đăng nhập hệ thống
- Quản lý sinh viên
- Thêm, sửa, xóa thông tin sinh viên
- Tìm kiếm sinh viên
- Quản lý lớp học
- Quản lý khoa/ngành
- Quản lý điểm sinh viên
- Thống kê dữ liệu sinh viên

## Yêu cầu hệ thống
- Windows 10 trở lên
- Visual Studio 2019/2022
- SQL Server
- .NET Framework hoặc .NET phù hợp với project
